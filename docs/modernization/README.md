# Baseline de modernizacion

Esta carpeta congela los contratos del backend antes de cambiar Java, Spring,
Hibernate, JHipster o Angular.

- `backend-contract.md`: API, JSON, JWT y semantica HTTP.
- `configuration-inventory.md`: propiedades consumidas.
- `validation-gates.md`: comandos reproducibles.

La evidencia ejecutable sigue en los `*ResourceIT`,
`UserJWTControllerIT`, `AccountResourceIT` y `ResourceAuthorizationTest`.
